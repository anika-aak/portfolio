# Anika AK — Portfolio

A minimal landing page for a PDF portfolio.

## Publish

In Settings → Pages, choose **Deploy from a branch**, **main**, and **/ (root)**, then save.

Expected site URL after publishing: https://anika-aak.github.io/portfolio/

## Add the portfolio

Upload the finished PDF to the repository root with the exact filename `portfolio.pdf`.
The landing page displays the PDF button once the file is available.

Direct PDF URL after publishing and uploading: https://anika-aak.github.io/portfolio/portfolio.pdf

Replace `portfolio.pdf` with future revisions while keeping its filename to preserve resume links.
